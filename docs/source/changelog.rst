0.1.0 — Initial release
------------------------

Added
~~~~~

- ``load_expression()`` function for vertex-wise hippocampal gene expression
  retrieval.
- Automatic atlas download and local caching (``~/.hippogenes/``).
- Custom cache directory support (``data_dir`` parameter).
- ReadTheDocs documentation with installation guide, usage reference, and
  four tutorials.
