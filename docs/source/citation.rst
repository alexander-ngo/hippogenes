Citation
========

Citing hippogenes
-----------------

If you use hippogenes in your research, please cite both the toolbox and the
underlying atlas data:

**hippogenes toolbox** ::

    REFERENCE FOR TOOLBOX (e.g. a preprint or software paper)

**Atlas data** — please cite the primary transcriptomic data source used to
construct the atlas ::
       
    REFERENCE FOR ATLAS DATA (e.g. Hawrylycz et al. 2012, Science)

Reporting bugs
--------------

Please open an issue on the GitHub repository:
https://github.com/alexander-ngo/hippogenes/issues

When reporting a bug, include:

- Your Python version (``python --version``).
- Your hippogenes version (``python -c "import hippogenes; print(hippogenes.__version__)"``).
- A minimal reproducible example.
- The full traceback if an exception was raised.
